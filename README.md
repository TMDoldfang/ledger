# 把錢丟進來(Ledger)— Android 記帳 App

本機優先的記帳 App:資料存在手機的 SQLite,不需要帳號。語音記帳為主要入口。

> **狀態:草稿階段。** 語音解析器有單元測試(117 項,已實際執行通過);
> Android 介面、線上更新、自動發佈則**還沒在 Android Studio / GitHub 上實際跑過**。
> 第一次 Sync 或執行若出現錯誤,把訊息貼給 Claude 即可。

## 技術棧
Kotlin 2.0、Jetpack Compose(Material 3)、Room 2.6 + KSP、Navigation Compose、
minSdk 26 / targetSdk 35、Gradle 8.9、AGP 8.7.3。

## 開啟與執行
1. Android Studio(Ladybug 以上)選 **Open**,指向這個資料夾,等 Gradle Sync。
2. 選模擬器或實機,按 Run。

## 功能
- **語音記帳**:首頁右下角大的麥克風。說「午餐 一百二 悠遊卡」,出現確認卡(金額、分類、帳戶、日期、備註),按「儲存」,或按「編輯」帶到完整表單微調。
  - 辨識出的文字框可以直接改,改了會重新解析,所以沒有語音服務時打字也能用。
  - 聽不出來的分類 / 帳戶會標示「(預設)」,不會悄悄猜。
- **代墊(朋友分攤)**:記「實付」和「我的份」,支出算實付全額,別人的部分變成「待收款」,收回的錢另列「代墊收回」(見下方)
- **轉帳**:繳信用卡費(銀行 → 信用卡)、投資 0050(銀行 → 投資帳戶)不算支出,避免重複計算
- **現金**:領現金時記一筆「現金領出」,之後用現金花的不用記;悠遊卡用零錢加值,不用另外記
- 手動記帳(小的 + 按鈕)、帳目列表(按月、依日分組、搜尋)、編輯與刪除(所有刪除都會先確認,確認框可勾「以後不再顯示」,設定頁可重新打開)
- 帳戶(現金 / 銀行 / 信用卡 / 電子支付):餘額由資料庫即時計算
- 分類管理、統計(支出圓環圖、近 6 個月收支)
- **線上更新**(管理頁底部):檢查、下載、安裝新版

## 語音記帳:能說什麼
| 說法 | 解析 |
|---|---|
| 午餐 120 悠遊卡 | 支出 120、餐飲、電子支付 |
| 晚餐花了兩百五用現金 | 支出 250、餐飲、現金 |
| 昨天買衣服一千二 信用卡 | 昨天、支出 1200、購物、信用卡 |
| 房租 一萬二 銀行轉帳 | 支出 12000、居住、銀行 |
| 薪水入帳 五萬三 | 收入 53000、薪資 |
| 三天前買書 三百五 | 3 天前、支出 350、學習 |
| 晚餐 一千二 我的三百 信用卡 | 實付 1200、我的 300、待收 900、信用卡 |
| 領現金 三千 銀行 | 支出 3000、分類「現金領出」、銀行 |
| 繳卡費 兩萬 銀行 | 轉帳 20000:銀行 → 信用卡(不算支出) |
| 0050 定期定額 三千 | 轉帳 3000:銀行 → 投資帳戶(「0050」不會被當成金額) |

支援中文數字(一百二、兩萬五、三千零五)、「1.5萬」、「NT$1,200」,會略過「一杯」「3 個」「12:30」「7-11」這類不是金額的數字。

## 自動偵測刷卡通知(設定頁,預設關閉)
讀取 LINE 裡「中國信託」「LINE錢包」兩個官方帳號的通知,先放進「待確認」(不算進統計),每晚 21:00 有待確認才提醒。
- 中信通知預覽寫明卡別:「LINE Pay聯名卡」→ LINE Pay 卡;「uniopen聯名卡」→ 統一企業卡;其他 → 未知的卡。
- LINE Pay 卡:兩分鐘內配對 LINE錢包 通知(「LINE Pay 付款 NT$ 13」)取得金額,先後順序不拘;配不到就金額空白。
- 統一企業卡:通知沒有金額,金額空白,按「記帳」時補。單獨出現的 LINE錢包 通知忽略。
- 首頁出現「待確認刷卡 N 筆」,點開按「記帳」會帶著卡別、金額、日期進編輯頁,存檔後該筆待確認消失。
- 開啟方式:設定頁打開開關 → 照提示到系統「通知存取」允許本 App。從 GitHub 安裝的 APK,Android 會先擋,
  要先到「應用程式資訊 → ⋮ → 允許受限制的設定」。
- 只處理 LINE 發出、標題含「中國信託」或「LINE錢包」的通知;設定頁會顯示最近一則 LINE 通知的標題(只存標題)供除錯。
- **尚未在真機驗證**:若偵測不到,看設定頁「最近一則 LINE 通知的標題」是什麼,回報給開發者調整比對規則。

## 截圖辨識(刷卡通知截圖)
- 入口:① 在相簿、LINE 等 App 按「分享」選「把錢丟進來」;② 首頁右下角的圖片按鈕,從相簿選圖。
- 讀出金額、日期時間、商店名稱;可「補到待確認裡還沒金額的那一筆」(例如 uniopen 卡),或「新增一筆帳目」。不會自動存任何東西。
- **資安**:用 ML Kit 內建中文模型在手機上辨識,不需要網路;圖片不上傳、不複製、不存檔;辨識文字只取金額、時間、商店,
  其餘(含卡號、卡末四碼)直接丟棄;商店名稱裡連續 4 位以上的數字與遮罩會被移除。
- **不綁銀行**:用通用的「金額 / 日期時間 / 商店」關鍵字與格式找(NT$、NTD、元;西元與民國年;特店名稱、消費商店等),
  不依賴某一間銀行的版面。需要加新關鍵字,改 `detect/ReceiptParser.kt` 並在 `ReceiptParserTest` 補一筆測試。
- 需要在 `app/build.gradle.kts` 的 dependencies 加一行:`implementation("com.google.mlkit:text-recognition-chinese:16.0.1")`。
- 目前「自動偵測 LINE 通知」那一塊仍是針對中國信託與 LINE錢包寫的;截圖辨識則是通用的。

## 代墊與待收款
1. 記帳時填「實付」和「我的份」(語音說「我的三百」/「我出三百」)。信用卡照實扣 1200,統計的餐飲只算 300。
2. 打開「有人分擔(代墊)」開關,選是誰欠(可多選,沒有這個人就按「＋新增」);預設平均分,每個人的金額可以再改。
   沒填「我的份」時,我的份 = 實付 − 大家的份。人也可以在「管理 → 代墊對象」先加好。
3. **不分月份**:沒收回就一直在待收款,不會因為跨月消失。首頁有提示;**統計頁最上面顯示待收代墊總額和每個人的長條**,
   點進去是明細(每個人、每一筆的日期、實付、原本該付、還欠多少)。
4. 朋友轉錢來:在明細按「已收到」,選轉進哪個帳戶(可以只收一部分),會記在那個人名下。這筆不算收入,只增加帳戶餘額。
5. **誰欠我可以之後再補**:只填了我的份、沒選人的部分會是「未指定是誰」。30 分鐘後還沒補,App 會發通知提醒;
   在明細按「指定是誰」補上。提醒由 WorkManager 排程,App 被關掉也會響。

**統計怎麼算(重要)**
- 支出 = 實付全額(含代墊)。收入不含代墊收回。朋友轉來的錢記成獨立的「代墊收回」,**不算收入**,但列入結餘:結餘 = 收入 − 支出 + 代墊收回。
- 首頁與統計頁只多一行小字:「支出含代墊 X · 本月收回 +Y(已列入結餘)」。
- 統計頁圓環圖:各分類只算我自己負擔的,另外多一塊「代墊」(別人該付的),全部加起來等於支出。
  代墊那一塊按**支出發生的月份**算,圖例寫「已收回 X · 待收 Y」,點開看每個人、每一筆;之後才收到錢,不會改掉那個月的數字,
  收回的錢列在收到的那個月。
- 跨月:待收款不分月份,沒收回一直在;11 月的支出看起來較重、收到錢的月份結餘較好,是現金流的真實樣子。
- **不收了**:待收款每一列都有「不收了」,按下去那部分不再是待收款,改算成你自己的支出(分類金額增加,代墊那一塊減少);
  該人的紀錄仍保留「累計代墊、不收了」的數字。
- **每個人的代墊統計**:管理頁 → 代墊對象,點某個人看累計、已收回、不收了、待收與每一筆明細。
- **待收款提醒**(設定頁,預設關閉):超過設定天數(預設 30,可隨時改)還沒收回就通知;每天 19:00 檢查,最多每 7 天提醒一次。
- 月額上限的算法不變(實付全額 + 轉到投資 − 收回,收回扣在收到的那個月)。

## 設定頁:基本功能與附加功能
底部「設定」分頁分兩段:**基本功能**(一直開著,只列清單)和**附加功能**(開關,預設都是關閉)。

| 附加功能 | 狀態 | 說明 |
|---|---|---|
| 月額上限與提醒 | 已做,預設關閉 | 打開開關時先設定金額(取消則維持關閉),之後隨時可在設定頁按「修改」;本月支出達 80%、100% 各通知一次;首頁摘要下方顯示進度條。算法(現金流角度):支出實付全額(含現金領出)+ 轉到投資帳戶(0050),朋友轉回來的代墊收回後扣掉(扣在收到的那個月,不會小於 0);繳卡費不算,避免和刷卡重複。月份是 1 號到月底。每次儲存帳目與 App 啟動時檢查 |
| 定期定額提醒 | 已做,預設關閉 | 可多組、扣款日與提醒日可隨時調整,見下一節 |
| 自動偵測訊息入帳 | **尚未推出**,預設關閉 | 設定頁只有一個不能點的開關。規劃:偵測 LINE 刷卡通知,先進「待確認」清單,再提醒分類。需要的資訊還沒齊(統一企業卡的通知樣本、通知欄截圖) |

## 定期定額提醒
**預設關閉**,到「設定」頁打開開關才會啟用(關掉會取消已排好的提醒)。

每個人的習慣不同,所以**扣款日、提醒日、組數都能隨時調整**:打開後在設定頁用「新增一組」「修改」「刪除」管理,
一組 = 名稱 + 每月幾號扣款 + 每月幾號中午提醒(1~31,超過該月天數就用月底)。預設一組:每月 6 號扣款、8 號提醒。
扣款日遇假日會順延的話,提醒日請設晚幾天。

金額不固定,所以**不自動入帳**。每組在自己的提醒日中午,App 會檢查扣款日所在的那個月有沒有「轉入投資帳戶」的紀錄,
沒有才發通知提醒你記一筆(語音說「0050 定期定額 三千」即可)。已經記過就不會打擾。
同一個月有好幾組時,依扣款日先後各要一筆記錄(第 2 組的提醒要有 2 筆才算記過),一筆記錄不會同時滿足兩組。
邏輯集中在 `reminder/InvestSchedule.kt`(提醒時間固定中午 12:00)。開關打開或設定一改就立刻重新排程,之後每月自動接續,App 重新啟動也會確認。

**怎麼調整它聽懂的詞**:規則集中在 `voice/VoiceParser.kt` 的幾張關鍵字表(`EXPENSE_KEYWORDS`、`ACCOUNT_KEYWORDS`…)。
建議先在 `app/src/test/.../VoiceParserTest.kt` 加一行測試,再改關鍵字;測試不需要模擬器,
在 Android Studio 對該檔案按右鍵 → Run,或執行 `./gradlew testDebugUnitTest`。

**已知限制**
- 一句話只能記一筆(「早餐 50 午餐 100」會只取一個金額)。
- 轉帳只認「繳卡費」「投資 / 0050 / 定期定額」兩種;其他帳戶間轉帳請用手動記帳的「轉帳」。
- 提醒是 30 分鐘後一次,不會重複提醒;通知權限被拒絕就不會響。
- 語音辨識用系統的 Google 語音服務,**需要網路**。
- 模擬器要用「Google Play」映像,並在模擬器側邊 ⋯ → Microphone 開啟「Virtual microphone uses host audio input」;不行的話直接在文字框打字測試。

## 線上更新
```
你改程式 → 推上 GitHub 的 main → GitHub Actions 自動:跑測試 → 打包 APK → 建立 Release(tag = v編號)
                                                                  ↓
手機上的 App:管理 → 檢查更新 → 下載 → 按「安裝」(系統確認)
```
- **設定**:把 `app/src/main/res/values/config.xml` 的 `update_repo` 改成 `你的帳號/倉庫名`。
- **Repo 必須是 Public**:App 讀 Release 不帶任何帳號或 Token(App 裡不能藏密碼)。
- **每次要按一下確認**:Android 不允許 App 靜默更新自己;第一次還要允許「安裝未知應用程式」,Play Protect 也可能跳出掃描提示。
- **簽章**:所有版本必須用同一把金鑰,否則無法覆蓋安裝。專案內附 `keystore/ledger.jks`(密碼在 `app/build.gradle.kts`),
  debug 與 release 都用它。這把金鑰**公開在 Repo 裡**——個人用、資料只存本機,風險很低;
  之後若要給別人用,改放 GitHub Secrets(`build.gradle.kts` 已支援用環境變數 `LEDGER_STORE_FILE` 等覆蓋)。
- **版本號**:`versionCode` = Actions 執行編號 = tag 數字(v12 → 12)。本機直接 Run 的版本是 1,
  所以只要 Release 存在(v2 以上)就會提示更新,可以在模擬器測試整個更新流程。
  反過來,裝過線上更新的版本(例如 5)後,再從 Android Studio 跑本機版(1)會被系統當成降版而失敗,先解除安裝即可。

## 設計取捨
- 金額存整數元(Long);有帳目的分類 / 帳戶不能刪(外鍵 RESTRICT)。
- 語音解析先用規則(快、免網路、免費);聽不懂複雜句子時,再考慮接 AI 解析。
- 信用卡目前當一般帳戶(刷卡 = 這張卡的支出),帳單日與繳款提醒之後再做。
- 資料庫已升到 v5(v3 新增代墊對象 people、每人分攤 shares;v4 新增待確認 pending_entries;v5 新增 shares.forgiven「不收了」),有 Migration,舊資料保留。舊版文字欄位「誰欠我」不會轉成人名(需要時請在明細重新指定)。
  Room 目前 `exportSchema = false`;正式使用前建議改 true。
- 「轉帳」「代墊收回」是系統分類,不會出現在分類選單。

## 待補金額提醒(可調)
- 設定 → 自動偵測通知入帳(開啟前會先顯示注意事項)。
- 提醒時間可自訂(預設 21:00,舊用戶維持 21:00),也可選「不提醒」。只排下一次,不使用週期性工作;改時間會先取消舊的再重排。
- 時間到時查所有金額為空的項目(不分日期):0 筆不通知,否則通知「你有 N 筆待補金額」(不顯示明細)。
- 點通知直接開啟待確認清單並只顯示「待補金額」(App 開著或關著都可以);項目補上金額或刪除後就不再算。
- 設定頁「還原所有提示」可把「以後不再顯示」的提醒全部恢復。

- 統計口徑更新:代墊收回**算進收入**,結餘 = 收入 − 支出(收入含代墊收回,支出為全額)。

## 自訂偵測來源
- 設定 → 自動偵測通知入帳 → 偵測來源:內建(LINE 中國信託、LINE錢包)可各自開關;可「新增來源」。
- 新增:從「最近收到的通知」(只存 App 名稱與標題,不存內容,可清除)挑一則,再指定標題關鍵字。**沒有「只比對 App」**,避免雜訊。
- 自訂來源用通用規則抓金額(金額/NT$/TWD/$/元);同一層出現不同數字就不收;**抓不到金額的通知一律忽略**。
- 每個來源可暫停/刪除,顯示「已收進 N 筆」。

## 通知延遲與交易日期
- 待確認清單標示「通知 月/日 時:分」。
- 待確認 → 記帳畫面:「用截圖補資料」(辨識在手機上、圖片不存檔、卡號不記)帶入日期、金額(空才填,不同只提示)、商店名稱(備註空才填)。
- 日期旁有「前一天」「前兩天」;顯示通知日期,選的日期跨月時提示。
